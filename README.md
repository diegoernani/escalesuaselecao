# Escale sua Seleção

App web para montar e compartilhar escalações.

## Site
https://www.escalesuaselecao.com.br

## Stack
- React + Vite
- Tailwind CSS
- Supabase
- Framer Motion

## Como rodar
```bash
npm install
cp .env.example .env   # preencha as variáveis do Supabase
npm run dev
```
