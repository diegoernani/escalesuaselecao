# Escale sua Seleção

App web para montar e compartilhar escalações.

## Demo
https://project-6jmwi.vercel.app

## Stack
- React + Vite
- Tailwind CSS
- Supabase
- Framer Motion

## Como rodar
```bash
npm install
cp .env.example .env   # preencha as variáveis do Supabase
npm run dev
```
